这里是 Probably Stolen 的非官方模组百科，收录各个 mod 的物品、机制和玩法指南。本站由贡献者在线维护，任何人都可以参与编辑。

## 数据从哪里来

物品的名称、描述、价格、贴图等基础数据，是用工具从模组的安装文件里提取出来的（manifest、CSV、本地化文本和贴图），与游戏内的表现一致。机制页和玩法指南由贡献者根据模组源码与数据文件整理，每条数值都注明来源；推不出来的写「待补充」，不做估算。

数据基线的日期显示在首页的通知条上。模组更新后，重新提取一次数据，物品和更新日志会自动跟着变。

## 免责声明

本站是玩家自发的非官方资料站，与模组作者和游戏开发商没有关系。模组的安装与兼容问题，请到对应 mod 的导航页查看是否有相关信息（例如该 mod 自己的「安装与兼容性」词条）；没有的话，以模组作者发布的说明为准。

## 怎么参与编辑

在浏览器里打开本站的 `/admin/`，用 GitHub 账号登录，就可以新建和修改页面：

1. **先找到 mod**。每个 mod 有自己的导航页，里面有它的物品图鉴、机制说明、更新日志。分区页把相关的 mod 归在一起。
2. **机制词条和物品词条都属于某个 mod**。新建时先选「所属 mod」，这一篇就会存进那个 mod 的目录。
3. **物品词条**：从「物品 ID」一栏的清单里选一件已导出的物品，文件名就是它的 ID。数据里还没有的新物品也可以自己起一个 ID，这时必须填「标题」，它就是物品在站上的名字。
4. **文件名**：规范是用小写英文加短横线，例如 `barrel-system`；也接受中文。点「设置文件名」可以自己定。
5. **从模板开始**：写机制页或物品词条时，正文上方有「从模板开始」按钮，选一个模板，内容会直接进编辑框，再按实际情况修改。

保存之后，网站会自动重新构建。如果内容有问题（比如同一件物品有两份词条、图片的格式不支持），构建会停下，并在提交记录里用中文说明是哪个文件、哪里不对、怎么改。改好之前网站不会更新。

## 模板

正文模板放在仓库的 `templates/` 目录里，在编辑器里只能查看，不能修改。要增删改模板，请通过 Pull Request 修改这个目录。

## 离线包

本站提供离线包，可以下载后在没有网络的地方直接打开，首页的搜索在离线包里同样可用。离线包发布在 [GitHub Releases](https://github.com/probably-documented/probably-stolen-mod-wiki/releases)，每隔几天更新一次。
