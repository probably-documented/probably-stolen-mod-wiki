title: 安装攻略

这一页讲怎么把模组装进游戏。各 mod 的具体前置和版本，以它们自己的导航页和「安装与兼容性」词条为准。


## 安装前先确认


1. **游戏版本**：模组声明了支持的游戏版本（例如 0.46、0.46D），版本对不上可能无法加载。
2. **前置模组**：大部分扩展模组需要先装主模组，到对应 mod 的导航页查看「必需前置」。
3. **备份存档**：装、卸模组之前先备份一份存档（存档位置：待补充）。


## 安装步骤


1. 下载模组压缩包，解压。
2. 把解压出的模组文件夹放进游戏的 `Mods` 目录（游戏目录的具体位置：待补充）。
3. 先放前置模组，再放扩展模组。
4. 启动游戏，在模组列表里确认前置和扩展都已启用。
5. 更新模组后，重启游戏。


## 安装目录名不等于 mod ID


有的模组，安装目录名和它的 mod ID 不一样。排查问题、填写前置时，以模组 manifest 里的 ID 为准。完整对照表见[安装与兼容性](../mechanics/install-compat.html)。


## 常见问题


- **装了但游戏里没有**：先查前置有没有装全、有没有启用，再查游戏版本是否匹配。
- **更新后出问题**：确认旧版文件已经删干净，不要让新旧版本的文件混在同一个目录里。
- **其他问题**：到对应 mod 的导航页查看，或以模组作者发布的说明为准。
