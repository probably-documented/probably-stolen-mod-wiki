*适用版本:可能更有互动(lewd_meme_legacy_content)v1.0.6,必需前置 lewd_meme(数据基线 2026-11-18)*

本模组为最新版 lewd_meme 恢复旧版魔改的内容层:标签、人物属性、阶段描述、双击对话、互动娇喘、提示补充与旧版夜报(据 lewd_meme_legacy_content manifest Description 与 README.md)。它**只补充内容层**,不使用旧 DLL 替换新版主体,也不新增物品 ID。

## 内容清单

- 角色标签、性格、敏感带和偏好(据 README)。
- 阶段描述、阵营描述、双击对话与旧版夜报(据 README)。
- 双击成年契约者时,随机播放一段娇喘表示互动成功;气泡不再播放原版逐字打字音效(据 README)。
- 双击浮动气泡保持原对话气泡的像素缩放,修复部分场景下跨画布缩放导致的文字发虚(据 README)。
- 在女性角色和触手本体提示中追加状态。
- 补充 [[wondrous_milk]]、[[tentacle_semen]]、[[ovulation_shot]] 与 [[tentacle_body]] 的使用文案(据 README)。

## 设置

在游戏"模组"菜单选中本模组,点齿轮按钮可开关**显示旧版夜报**(据 README):

- 默认关闭:不再显示自己的夜报窗口,也不替换主模组夜报,避免与其他模组的夜报叠加后超出窗口。
- 关闭时夜间数值结算(发情、绝顶、产奶等)仍然保留,只是不显示旧版夜报窗口。
- 设置按模组保存在游戏配置目录,对所有存档共用。

## 兼容性(1.0.6)

- 不再改写主模组现有物品与人物(少女)的名字,不覆盖主模组的势力、体型、乳量词条;本模组自有内容改用 LEGACY_LC 前缀键与自有展示标签保存(据 README 1.0.6 段)。
- 不新增或替换物品 ID:子模组停用后,主模组物品仍保留;本模组写入的附加标签与模块数据不会在普通停用时自动清除(据 README 存档段)。
- 主模组更新后若报告"挂接旧版内容补丁失败",优先核对主模组版本,而不是替换主模组 DLL(据 README 说明段)。
