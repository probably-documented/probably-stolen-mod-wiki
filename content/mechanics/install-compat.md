# 安装与兼容性

本页是在线 wiki 骨架的占位条目,对应导航栏的「关于本站」。安装与兼容性的细节会随内容编辑流程逐步补充,当前只列出通用的辨识规则。

## 安装目录名不等于 mod ID

触手家族模组的安装目录名与 mod ID 并不一致:例如暗流交易安装在 LewdMemeShadowTrade 目录,mod ID 却是 lewd_meme_remake。排障、写前置或查管制品时,一律以模组自己的 manifest 中的 ID 为准。

## 前置关系与版本

各模组的前置关系以其 manifest 的 Prerequisites 段为准,版本号以 ModVersion 段为准。本站「模组介绍」与「更新日志」页展示的是数据基线时的提取结果。
